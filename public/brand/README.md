# ACOS — identidad oficial

Origen: **ACOS_Manual-de-Marca (1).pdf**, edición 01, octubre de 2026, entregado por el cliente el 11 de noviembre de 2026. Autoría del manual: Marlon S. Soza / Innovart Studio.

Los PNG son las imágenes originales incrustadas en el PDF con su canal alfa, extraídas sin redibujar, recortar, recolorear, deformar ni recomponer:

- `acos-primary.png`: versión principal sobre fondo claro, página 7.
- `acos-horizontal.png`: versión secundaria horizontal sobre fondo claro, página 7.
- `acos-horizontal-negative.png`: versión horizontal para fondos oscuros, páginas 1 y 20.
- `acos-primary-negative.png`: versión principal para fondos oscuros, página 8.
- `acos-symbol.png`: isotipo, páginas 1 y 7; utilizado como favicon y en espacios compactos.

El original verde/plata anterior se sustituye en todas las superficies. `/acos-logo.png` conserva la ruta histórica para los metadatos sociales, con el nuevo arte principal.

No aplicar filtros, sombras, efectos, rotaciones o recoloraciones a estos archivos. El componente `BrandLogo` elige la versión correcta. Mínimos de referencia: principal 180 px, secundaria 220 px, isotipo 24 px. En navegación móvil se utiliza el isotipo para evitar comprimir el descriptor.
